# FRET-based Sensor Analysis

## Overview
This pipeline performs FRET-based image analysis from paired donor and acceptor fluorescence images.

The workflow loads donor and acceptor channels together with a binary segmentation mask, computes per-cell FRET efficiency values, and generates visualization outputs including pseudocolor maps and summary tables.

The pipeline is designed for simple and reproducible per-cell FRET quantification.

---

## Repository Structure

### `FRET_analysis.ipynb`
Main notebook for running the full FRET-based sensor analysis workflow.

### `example_image&mask/`
Example dataset used to test the pipeline.

### `FRET_analysis_functions/`
Helper functions used by the analysis notebook.

- Contains `fret_utils.py`
- Includes functions for:
  - image loading
  - signal extraction
  - FRET calculation
  - pseudocolor visualization
  - output generation

### `FRET_analysis_output/`
Output folder generated by the pipeline.

---

## Features

- Per-cell FRET efficiency quantification
- Analysis from donor and acceptor fluorescence images
- Binary-mask-based cell segmentation
- Per-cell signal extraction
- Pseudocolor FRET visualization
- Export of CSV summary tables
- TIFF output generation for publication-quality figures

## Input Data

The analysis requires:

- `donor.tif`
  - donor fluorescence channel

- `acceptor.tif`
  - acceptor fluorescence channel

- `binary_mask.tif`
  - binary segmentation mask based on the NN
  
All images should:

- have identical dimensions
- be spatially aligned
- correspond to the same field of view

---

## Workflow

### 1. Load Images

The notebook loads:

- donor channel
- acceptor channel
- binary segmentation mask

---

### 2. Segmentation-Based Signal Extraction

The binary mask is used to identify individual segmented regions.

Signal intensities are extracted independently from:

- donor image
- acceptor image

for each segmented object.

---

### 3. FRET Efficiency Calculation

Per-cell FRET efficiency values are computed from donor and acceptor signals.

The resulting values are stored in a summary table.

---

### 4. Visualization

The pipeline generates:

- segmentation preview image
- pseudocolor FRET map
- FRET color scale bar

These outputs allow rapid visualization of spatial variation in FRET efficiency.

---

## Output

Typical outputs include:

- `cell_FRET_efficiency.csv`
  - per-cell FRET measurements

- `EFRET_per_cell_pseudocolor.tif`
  - pseudocolor visualization of FRET efficiency

- `segmentation_preview.tif`
  - segmentation quality-control image

- `EFRET_color_scale_bar.tif`
  - color reference scale

---

## Notes

- Ensure donor and acceptor channels are properly aligned before analysis.
- Mask quality directly affects FRET quantification accuracy.
- Consistent visualization ranges should be maintained across experiments for comparison.
- File paths inside the notebook may need adjustment before running on a new system.
